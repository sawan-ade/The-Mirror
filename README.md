# THE MIRROR 🌌

> **"Your thoughts, reflected back to you."**

An AI-powered interactive visualization that transforms your unstructured thoughts, notes, journals, and ideas into a **living planetarium of your intellectual world** — featuring photographic memory anchors, voice reflections, and temporal evolution.

Built with **Claude Sonnet** for the Anthropic & HackerRank Hackathon 2026.

---

## 🎨 Aesthetic & Design

Inspired by the **HackerRank Orchestrate** aesthetic:
- **Matte Charcoal & Void Black** (`#0A0A0A`, `#111111`)
- **Electric Acid Lime Accent** (`#A8FF3E`, `#BBFF52`)
- **Renaissance Oil Painting Atmosphere**: A living painted cosmic background that transforms your thoughts into fine art
- **Warm Editorial Typography**: *Playfair Display* serif headlines + crisp *Inter* UI + monospace metadata

## 🎯 Groundbreaking Features

| Feature | Description |
|---|---|
| 🌌 **Galaxy Thought Map** | Interactive constellation — concepts as glowing stars, relationships as dynamic light threads |
| 📸 **Visual Memory Anchors** *(NEW)* | Attach personal photos to any concept. Hover to preview thumbnails; click to open full-screen Lightbox; explore in the Visual Memories Gallery |
| 🎙️ **Voice Thoughts** *(NEW)* | Record voice reflections directly attached to nodes with waveform animation and speech playback |
| 📅 **Temporal Evolution Scrubber** *(NEW)* | Scrub through time (2024–2026) or click **Play Evolution** to watch your mind's ideas emerge, transform, or fade |

| 🔍 **Concept Inspector** | Click any node to view mentions, cognitive weight, timeline, AI cognitive interpretation, and raw journal quotes |
| ◈ **Hidden Connections** | Uncovers non-obvious bridges between distant thoughts you never consciously connected |
| ◎ **Forgotten Ideas** | Highlights concepts that burned bright then quietly faded away |

| 💫 **Instant Demo Mode** | Pre-loaded with an 18-month software engineer journal (25 concepts, 5 clusters, photographic memories) — zero setup required |

## 🛠 Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 (Custom Design Tokens), Canvas 2D (Cinematic Constellation Engine)
- **Backend**: Python 3.8+ (Flask, Flask-CORS) / Node.js Express fallback
- **AI Architecture**: Claude Sonnet via `@anthropic-ai/sdk`
- **Zero Framework Bloat**: Pure vanilla JS, no heavy npm build steps, instant load time under 300ms

## ⚡ Quick Start

### Option 1: Double-Click (Windows)
Simply double click `start.bat`.

### Option 2: Python Server
```bash
# 1. Clone the repository
git clone https://github.com/sawan-ade/The-Mirror.git
cd The-Mirror

# 2. Install dependencies
pip install flask flask-cors anthropic

# 3. (Optional) Set your Anthropic API Key
set ANTHROPIC_API_KEY=sk-ant-your-key-here     # Windows
export ANTHROPIC_API_KEY=sk-ant-your-key-here  # Mac/Linux

# 4. Start the server
python server/server.py

# 5. Open in browser:
http://localhost:3001
```

> **No API key?** No problem! The built-in Demo mode works out of the box with rich photographic memories, timeline playback, and interactive insights.
